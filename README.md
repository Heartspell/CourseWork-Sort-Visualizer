# Course Project: **Sorting Algorithms Visualization in C++ Using OOP**

This course project focuses on the development of a graphical application for visualizing sorting algorithms using object-oriented programming in C++. The goal is to provide an intuitive and interactive way to understand how sorting algorithms operate by observing their step-by-step execution.

The project utilizes **SFML (Simple and Fast Multimedia Library)** to render smooth, real-time animations of sorting processes. Users can visually follow the transformation of the dataset, observe comparisons and swaps, and gain a deeper understanding of algorithmic logic.

Each sorting algorithm is encapsulated in its own class, adhering to a common interface. This architecture follows OOP principles such as encapsulation, inheritance, and polymorphism, making the project scalable, maintainable, and modular.

### Features:
- Real-time visualization of sorting procedures
- Clean and interactive user interface
- Object-oriented and modular design
- User-defined input and configuration options
- Performance insights through visual behavior

This application serves as an educational tool for students and anyone interested in learning or teaching sorting algorithms through visual exploration.

### Algorithms included:
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
